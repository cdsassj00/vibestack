파이썬 라이브러리 자바스크립트 라이브러리 API

키 관리 인증키는 브라우저 코드(HTML·JS)에 넣지 않습니다. 서버나 서버리스 함수(Cloudflare Worker 등)에 비밀값으로 두고 중계합니다. 행정망·폐쇄망에서는 외부 API가 막혀 있는 경우가 많아, 쓰기 전에 망 연계나 방화벽 허용 여부를 확인합니다.
