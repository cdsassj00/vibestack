# VibeStack 디자인 규칙 (현재 적용본)

opencabinet.cc(ssjsite 스킬로 만든 사이트)의 애플 다크 톤을 옮겨 온 디자인입니다. 실제 값은 `style.css`(공통)와 `curriculum/curriculum.css`(두 교육과정 보드 전용)에 있고, 이 문서는 그 값을 정리한 것입니다.

## 1. 원칙

| 항목 | 규칙 |
|---|---|
| 색 | `style.css` 상단 `:root` 토큰만 씁니다. 보드 CSS도 토큰에서 파생한 별칭만 씁니다 |
| 배경 | 순수 블랙(라이트 모드는 `#f5f5f7`) |
| 표면 | 무채색 계단 surf → tint → tint2. 다크 모드에서는 그림자 없이 표면 밝기로 층을 나눕니다 |
| 애니메이션 | 넣지 않습니다. keyframes, 스크롤 등장, 카운트업, 호버 이동·확대 금지 |
| 호버 | 색·배경·테두리 변화만 줍니다(`transition` 0.15s, 색 속성만) |
| 아이콘 | 이모지를 쓰지 않습니다. `app.js`의 `ICONS`(SVG 라인 아이콘), 색 칩, 색 점으로 표현합니다 |
| 문구 | 합니다체로 짧고 담백하게 씁니다. 느낌표와 과장 표현(완벽, 100%, 초고속, 압도적, 차세대 등)을 쓰지 않습니다 |
| 제목 | 비유·은유 없이 기능이나 대상을 그대로 적습니다. 예: "생성형 AI 교육과정 설계 보드", "업무 영역 × AI 활용 방법 매트릭스" |
| 확인 범위 | 다크·라이트 모드, 모바일(640px 이하)을 함께 확인합니다 |

| `--tint` | `#2c2c2e` | `#f2f2f7` | 보조 버튼, 입력, 칸 줄무늬 |

### 칩 색 (틴트 배경 + 채도 낮춘 글자)

## 7. 교육과정 보드 전용 (`curriculum/curriculum.css`)

색은 모두 위 토큰에서 가져옵니다.

| 대상 | 규칙 |
|---|---|
| 세로축 L1~L4 배지 | L1 무채색(`--tint2`) → L2 블루 틴트 → L3 블루(흰 글자) → L4 골드(검정 글자, 라이트 모드는 검정 바탕 골드 글자) |
| S5 배지(바이브코딩 보드) | 퍼플 틴트 |
| 행 머리 | 왼쪽 4px 색 막대(L1 회색, L2 연블루, L3 블루, L4 골드, S5 퍼플) |
| 칸 | 행마다 줄무늬, 호버·선택은 배경·테두리 색만 바꿉니다 |
| 망 환경 표시 | 폐쇄망 대안 있음(B) 초록, 외부망 준비 후 반입(I) 회색, 외부망 필요(E) 주황 |
| 담은 모듈·맞춤 실습 | 골드 틴트 배경 + 골드 글자 |
| 경고 | 빨강 틴트 배경, 둥글기 14px |
| 매트릭스 표시 | [간단히] 보기는 짧은 이름 `st`만, [자세히] 보기는 전체 이름·예시 수·도구 |

## 8. 반응형

| 폭 | 바뀌는 것 |
|---|---|
| 900px 이하 | 헤더 섹션 링크 숨김, 2단 카드는 1단 |
| 640px 이하 | 메인 페이지 헤더 2줄(높이 100px): [아이콘 · 서비스 선택 짧은 이름 · 테마] / [섹션 버튼]. 브랜드 이름 숨김. 여백 16px, 섹션 간격 64px, 폼 2열은 1열 |
| 640px 이하(보드) | 보드 헤더는 한 줄 유지(높이 56px) |
| 인쇄 | 테마와 관계없이 흰 종이·검정 글자(`--print-*` 토큰) |

## 9. 코드에서 지킬 것

- 새 색이 필요하면 하드코딩하지 말고 `:root`와 `[data-theme="light"]`에 토큰을 함께 추가합니다.
- 데이터 파일에서 온 문자열은 속성값까지 `escapeHtml()`을 거쳐 `innerHTML`에 넣습니다.
- 숨김 요소는 `[hidden]{display:none}`이 덮이지 않게 합니다(`display:grid` 등이 `hidden` 속성을 이기지 않게).
