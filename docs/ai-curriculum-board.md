# 생성형 AI 교육 설계 보드 — 작업 기록

작성일: 2026-09-23 · 요청자: 신성진(CDSA) · 작업: 기관 맞춤형 생성형 AI 교육 설계 컨설팅용 로드맵·사이트

## 1. 출발점
강사 양성·기관 맞춤형 교육 설계 컨설팅에 쓸 생성형 AI 교육 로드맵을 매트릭스(가로 업무 영역 × 세로 난이도)로 만들고, 기관이 이것만 보고 무엇을 가르칠지 고를 수 있는 사이트로 공개하는 것이 목표였다.

## 2. 축 설계에서 정한 것
- 처음 안에서는 가로축에 업무 영역과 구현 방식(업무 자동화, 외부 API·폐쇄망, 프로그램 개발)이 섞여 있었다. 자동화는 모든 영역에 걸치는 방식이므로 열이 아니라 세로축 단계로 옮겼다.
- 망 환경(외부망·폐쇄망)은 축이 아니라 필터로 분리했다. 공공기관은 망 환경을 먼저 진단하고 쓸 수 없는 칸을 가리는 방식으로 설계한다.
- 도구 이름은 축이 아니라 칸 안의 내용으로 둔다. 도구는 자주 바뀌기 때문이다.
- 최종 가로축(업무 영역): 리서치·지식검색 / 문서 작성·편집 / 콘텐츠 제작 / 데이터 분석 / 업무처리·연계 + 공통 기반·프로젝트 띠
- 최종 세로축(AI 활용 수준)
  - L1 대화형: 이미 있는 서비스에 묻기 (범용·특화 AI, 이미지·영상·슬라이드 생성 서비스, 폐쇄망 로컬 챗)
  - L2 위임형: 이미 있는 에이전트에 맡기기 (딥리서치, 에이전트 모드, 젠스파크·마누스, 앱 생성 서비스). 외부망 전용
  - L3 제작형: AI가 짜준 코드로 도구 만들기 (VBA·Python·HTML·JS·PowerShell·Apps Script)
  - L4 구축형: 에이전트·시스템을 직접 구축 (코딩에이전트 하네스, 배포·DB·RAG·MCP, 로컬 LLM)
- 폐쇄망에서 L2가 비는 것은 당연하다. 기관 LLM API와 오픈소스 코딩 하네스(OpenCode 등)로 위임형을 만드는 것은 "이미 있는 것"이 아니라 L4 구축형이다. 폐쇄망 기관은 L1에서 L3로 건너뛰고, 전산 담당자가 L4로 위임형 에이전트를 만들어 직원이 그 위에서 쓰는 구조로 설명한다.
- 난이도(입문~프로젝트)는 세로축과 별도로 둔다. 예: 코딩에이전트 체험은 L4지만 난이도는 기초.

## 3. 모듈 계층에서 정한 것
- 개별 실습 카드(138개)는 너무 세밀해 강사 재량과 확장성을 떨어뜨렸다. 이를 역량 모듈 34개로 묶고, 세부 실습은 모듈 안의 "실습 예시"로 작게 적었다.
- 과정표에는 역량 모듈을 담고, 이번 과정에서 다룰 실습 예시는 강사가 체크해서 고른다. 고르지 않으면 "강사 재량"으로 나간다.
- 예: HTML·CSS·JS는 "브라우저에서 돌아가는 HTML·CSS·JS 도구" 한 모듈로 묶고 북마클릿, 콘솔 추출, 드래그앤드롭 읽기, 로컬 저장, 차트·필터, 인쇄 양식 등을 예시로 둔다.
- 추가 반영한 무료·생성 도구: Google AI Studio, Google Stitch, Lovable, Replit, Bolt, v0, Firebase Studio, Base44
- 각 모듈에 공공 적용·민간 적용 사례를 2건씩 적었다. 형식은 "기관·부서 / 직무" + "어떤 업무를 AI로 어떻게 하는지" 한 문장.
- 인재개발원 과정 모듈은 기술 요소 참고용이었으므로 예시 과정(프리셋)과 사이트 문구에서 제외했다. 남은 예시 과정은 "전 직원 입문 1일", "폐쇄망 기관 2일" 두 개다.

## 5. 디자인
- ssjsite 스킬은 이 채팅 환경에 없어 찾지 못했다.
- 사용자 사이트 열린국무회의(opencabinet.cc)의 디자인을 가져왔다: 검정 배경, #1c1c1e 둥근 카드, 파랑 강조 #0a84ff, 금색 #ffd257, 상단 금색 띠·블러 내비·가운데 정렬 히어로, 알약형 버튼·칩. 라이트 모드 사용자는 같은 구조의 밝은 버전으로 보인다. 글꼴은 Pretendard만 사용.

## 6. 사이트와 데이터
- 공개 위치: claude.ai 아티팩트 https://claude.ai/artifact/CT8k1uJShGqLGoxxbJqGag (Vercel·Cloudflare가 아님)
- 모듈과 후보는 아티팩트에 붙은 저장 공간(db)에 들어 있어, 사이트의 "모듈 추가·수정·모듈로 등록"이 바로 반영된다. 편집은 주인·편집 권한자만 가능하며, 이 때문에 조직 내부 로그인 사용자만 볼 수 있다.
- 구글 시트로 관리할 때: 사이트의 "시트용으로 복사" → 시트에서 수정 → "구글 시트에서 붙여넣기"
- 시트 수정이 자동 반영되는 외부 공개 사이트가 필요하면 Vercel·Cloudflare에 별도 배포해야 한다(미완료).
